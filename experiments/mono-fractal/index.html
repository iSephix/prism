PRISM Mono-Fractal Capacity Lab

Measure the empirical information capacity of black/white 8×8 microtextures through your real printer → paper → camera channel.

1 · Generate the target

The sheet contains 256 balanced 8×8 glyphs, each repeated four times in a deterministic 32×32 layout. Print the exact same sheet twice as independent physical copies A and B, at 100% scale with no “fit to page”.

2 · Calibrate on print A

Photograph the complete target. Auto-detection searches for the four large black fiducials; if it misses, click their centers in order: top-left → top-right → bottom-right → bottom-left.

3 · Blind test on independent print B

Protocol

For each pitch: print two copies, calibrate from A, evaluate B. Then repeat with normal indoor light, oblique capture and greater distance. Do not use the same physical print for both stages if you want the result to mean anything.
