EXPERIMENTAL · MONO-FRACTAL
Measure how much information paper can actually carry.
This mode probes the real black/white printer → paper → camera channel with 8×8 microtextures. It does not change the Prism 19 wire format.


      

        
TARGET
1 · Generate the calibration sheet

        

          

          

        

        
256 balanced 8×8 monochrome glyphs, each repeated four times in a deterministic 32×32 layout. Print the exact same SVG twice as independent physical copies A and B, at 100% scale with no “fit to page”.

        

        

      


      

        

          
CALIBRATE
2 · Learn print A

          
          
Photograph the complete target. Auto-detection estimates the four fiducials. If needed, click them top-left → top-right → bottom-right → bottom-left.

          

          

          

        


        

          
BLIND TEST
3 · Test independent print B

          
          
Use a separately printed copy. Print B is never used for codebook selection or calibration.

PROTOCOL
Run order

        
Start at 2.0 mm. Print two copies. Calibrate A, blind-test B. Then repeat with smaller pitches, normal indoor light, oblique capture, and greater distance. Keep the complete target and all four fiducials visible.
